# 동물로 태어나기

다음 생에 **한국에서** 동물로 태어난다면, 어떤 삶을 살게 될까?
실제 통계를 바탕으로 동물의 삶을 체험하는 웹 게임입니다.

**▶ 플레이: https://anth0ny0412.github.io/born-as-an-animal/**

- 자동 진행(발표·전시용): https://anth0ny0412.github.io/born-as-an-animal/?auto=1
  (속도는 `&speed=slow`, `&speed=fast`)

## 무엇을 체험하나요

- **현실 모드**: 국내 추정 개체 수 비율대로 태어나요. 대부분 개미, 그다음은 꿀벌·양식 물고기·닭이에요.
- **도감 모드**: 모든 동물이 같은 확률로 나와요.
- 동물 32종, 삶 50개: 곤충, 가축, 반려동물, 도시 동물, 야생 동물, 바다 동물, 멸종위기종
- 결과 화면: 내가 산 기간과 자연 수명, 사람이 영향을 준 비율, 같은 날 태어난 1,000마리와의 비교, 근거 자료
- 첫 화면의 "자료 출처"에서 어떤 숫자가 확인된 통계이고 어떤 숫자가 추정·가정값인지 볼 수 있어요.

## 개발

빌드 과정 없이 `index.html`을 브라우저로 열면 됩니다.

```
data/         동물별 데이터 (사건, 선택지, 확률), species.js(뽑기 목록), sources.js(출처)
js/engine.js  게임 규칙
js/main.js    화면
js/auto.js    자동 진행
tests/        검사와 밸런스 확인
```

- `npm test`: 전체 검사 (데이터 실수, 모든 삶의 경로, 화면 그리기). 빠르게 볼 때는 `RUNS=3000 npm test`
- `npm run balance`: 삶마다 수명, 생존율, 사람 원인 사망 비율
